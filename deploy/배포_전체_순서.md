# 배포 전체 순서 (로컬 수정 → 빌드 → 푸시 → 웹서버)

**한 번만 이 순서대로 하면 됩니다.**

---

## 1. 로컬에서 수정

- Cursor/VS Code에서 코드 수정
- 저장 (Ctrl+S)

---

## 2. 로컬에서 빌드

**PowerShell (로컬 PC):**

```powershell
cd C:\Users\USER\Desktop\venysuond.com
npm run build
```

- **에러가 나오면** → 에러 메시지 확인 후 수정하고 다시 `npm run build`
- **에러 없이 끝나면** → 3단계로

*(경고만 나오고 "Done" 나오면 성공)*

---

## 3. GitHub에 푸시

**PowerShell (로컬 PC):**

```powershell
cd C:\Users\USER\Desktop\venysuond.com
git add .
git status
git commit -m "기능 수정 또는 배포"
git push origin main
```

- `git add .` → 수정한 파일 모두 스테이징  
- `git status` → 올라갈 파일 확인 (선택)  
- `git commit` → 커밋  
- `git push origin main` → GitHub에 올리기  

*(`local-uploads/` 는 보통 .gitignore 되어 있음)*

---

## 4. 웹서버에서 DB 적용 (필요할 때만)

**공지/테이블 관련 수정을 배포했을 때만**, 서버에서 **한 번** 실행:

**서버 SSH 접속 후:**

```bash
cd /var/www/venysound/app
npm run db:site-announcements
```

- "site_announcements 테이블 생성 완료." 나오면 끝  
- 공지 기능 안 건드렸으면 이 단계 **생략**

---

## 5. 웹서버에서 배포 (코드 반영)

**서버 SSH 접속 후:**

```bash
cd /var/www/venysound/app
git pull
npm install
npm run build
pm2 restart venysound
```

**한 줄로 실행하려면:**

```bash
cd /var/www/venysound/app && git pull && npm install && npm run build && pm2 restart venysound
```

- `git pull` → GitHub에서 최신 코드 받기  
- `npm install` → 패키지 설치 (tsx 등 빌드에 필요)  
- `npm run build` → 클라이언트·서버 빌드  
- `pm2 restart venysound` → 앱 재시작  

**앱 경로가 다르면** `cd` 뒤만 실제 경로로 바꾸면 됩니다. (예: `/var/www/venysound`)

---

## 요약 체크리스트

| 단계 | 어디서 | 할 일 |
|------|--------|--------|
| 1 | 로컬 | 코드 수정 & 저장 |
| 2 | 로컬 | `npm run build` |
| 3 | 로컬 | `git add .` → `git commit -m "..."` → `git push origin main` |
| 4 | 서버 | (공지 등 DB 변경 시) `npm run db:site-announcements` |
| 5 | 서버 | `git pull` → `npm install` → `npm run build` → `pm2 restart venysound` |

---

이 순서만 기억하면 됩니다.
